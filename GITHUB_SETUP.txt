HOW TO GET YOUR PORTFOLIO CODE INTO VSCode AND PUSH TO GITHUB
================================================================================

PART 1: DOWNLOADING THE PROJECT AND SETTING UP LOCALLY
================================================================================

OPTION A: Download from v0 (Recommended)
-----------
1. Click the three dots (•••) in the top right corner of the Code Project
2. Select "Download ZIP"
3. Extract the ZIP file to your desired location
4. Open Terminal/Command Prompt in the extracted folder
5. Follow "SETTING UP THE PROJECT LOCALLY" section below

OPTION B: Using Git Clone
-----------
If you already have the project on GitHub:

1. Open Terminal/Command Prompt
2. Navigate to where you want to store the project:
   cd /path/to/your/projects

3. Clone the repository:
   git clone https://github.com/yourusername/portfolio.git

4. Navigate into the project:
   cd portfolio

5. Skip to "SETTING UP THE PROJECT LOCALLY" section


PART 2: SETTING UP THE PROJECT LOCALLY
================================================================================

1. Open the project folder in Visual Studio Code:
   - Open VSCode
   - Click "File" > "Open Folder"
   - Select the portfolio folder
   - Click "Open"

2. Open Terminal in VSCode:
   - Press Ctrl + ` (backtick) or go to Terminal > New Terminal
   
3. Install dependencies:
   npm install
   
   This will install all required packages listed in package.json
   (This may take 2-5 minutes)

4. Start the development server:
   npm run dev
   
   You should see:
   ▲ Next.js 16.0.0
   Local: http://localhost:3000

5. Open in browser:
   - Click the link or go to http://localhost:3000
   - Your portfolio should load!

6. To stop the server:
   Press Ctrl + C in the Terminal


PART 3: CUSTOMIZING YOUR PORTFOLIO
================================================================================

1. Update your personal information in these files:

   📝 Homepage: app/page.tsx
      - Change "Your Name" to your actual name
      - Update the introduction text
      - Replace the image path

   📝 About Page: app/about/page.tsx
      - Edit the about section
      - Update experience and education
      - Replace the profile image
      - Add link to your CV/Resume

   📝 Projects Page: app/projects/page.tsx
      - Replace project titles and descriptions
      - Update project images
      - Add your GitHub and demo links
      - Update skills list

   📝 Contact Page: app/contact/page.tsx
      - Update your email address
      - Add your location
      - Update social media links (GitHub, LinkedIn, Twitter)

   📝 Header: components/header.tsx
      - Change "Portfolio" logo text to your name

   📝 Footer: components/footer.tsx
      - Update the year and copyright info
      - Update social media links

2. Add your images:
   - Put your images in the public/ folder
   - Replace /placeholder.svg references with your image paths
   - Example: src="/images/my-photo.jpg"

3. Change colors (optional):
   - Edit app/globals.css
   - Look for the @theme section
   - Customize colors to match your brand

4. Test your changes:
   - Changes auto-reload in the browser
   - Just save the file in VSCode


PART 4: CREATING A GITHUB REPOSITORY
================================================================================

STEP 1: Create a GitHub Account
-----------
If you don't have one:
1. Go to https://github.com
2. Click "Sign up"
3. Follow the prompts to create your account
4. Verify your email

STEP 2: Create a New Repository
-----------
1. Click the "+" icon in the top right corner of GitHub
2. Select "New repository"
3. Fill in the details:
   - Repository name: "portfolio" (or your preferred name)
   - Description: "Personal Portfolio Website"
   - Choose "Public" (so others can see your work)
   - Do NOT check "Initialize this repository with a README"
   - Click "Create repository"

STEP 3: Get Your Repository URL
-----------
After creating the repo, you'll see a page with:
"...or push an existing repository from the command line"

You'll need these commands - but we'll use git in VSCode instead.


PART 5: PUSHING YOUR CODE TO GITHUB
================================================================================

METHOD 1: Using VSCode (Easiest)
-----------

1. Open Source Control in VSCode:
   - Click the Source Control icon on the left sidebar (looks like a branch)
   - Or press Ctrl + Shift + G

2. Initialize Git (if not already done):
   - Click "Initialize Repository"
   - This creates a .git folder in your project

3. Stage your files:
   - You'll see a list of changed files
   - Click the "+" icon next to "Changes" to stage all files
   - Or click "+" next to individual files

4. Commit your changes:
   - Type a message like "Initial commit: Add portfolio website"
   - Press Ctrl + Enter or click the checkmark icon
   - This saves your changes locally

5. Set up the remote repository:
   - Open Terminal (Ctrl + `)
   - Copy and paste this command (replace with your GitHub username):
   
   git remote add origin https://github.com/yourusername/portfolio.git

6. Push to GitHub:
   - In the Source Control panel, click the "..." menu
   - Select "Push"
   - Or type in Terminal: git push -u origin main
   - It may ask for your GitHub credentials - enter them

7. Verify on GitHub:
   - Go to https://github.com/yourusername/portfolio
   - You should see all your files!


METHOD 2: Using Terminal Commands (Manual)
-----------

1. Initialize git in your project:
   git init

2. Add all files:
   git add .

3. Create your first commit:
   git commit -m "Initial commit: Add portfolio website"

4. Add the remote repository (replace yourusername):
   git remote add origin https://github.com/yourusername/portfolio.git

5. Push to GitHub:
   git branch -M main
   git push -u origin main

6. Enter your GitHub credentials when prompted


PART 6: DEPLOYING TO VERCEL (LIVE ON THE WEB)
================================================================================

Vercel is the easiest way to deploy your Next.js portfolio online!

STEP 1: Connect GitHub to Vercel
-----------
1. Go to https://vercel.com
2. Click "Sign Up"
3. Choose "Continue with GitHub"
4. Authorize Vercel to access your GitHub account

STEP 2: Import Your Repository
-----------
1. After signing in to Vercel, click "New Project"
2. Click "Import Git Repository"
3. Find and select your "portfolio" repository
4. Click "Import"

STEP 3: Configure and Deploy
-----------
1. The configuration should be auto-detected
2. Click "Deploy"
3. Wait for deployment to complete (2-5 minutes)
4. You'll get a live URL like: https://portfolio-xxxxx.vercel.app

STEP 4: Your Portfolio is Live!
-----------
- Share your URL with others
- Any changes you push to GitHub will automatically deploy to Vercel
- Visit Vercel dashboard to see deployment details

TROUBLESHOOTING
================================================================================

❌ "npm install" doesn't work
→ Make sure you have Node.js installed
→ Download from https://nodejs.org (LTS version)
→ Restart VSCode after installing Node.js

❌ "Cannot find module" errors
→ Delete node_modules folder: rm -r node_modules
→ Delete package-lock.json file
→ Run npm install again

❌ Port 3000 already in use
→ Run the dev server on a different port: npm run dev -- -p 3001
→ Or kill the process using port 3000

❌ GitHub authentication fails
→ Use a Personal Access Token instead of password:
→ Go to GitHub Settings > Developer settings > Personal access tokens
→ Create a new token with 'repo' permissions
→ Use that token instead of your password

❌ Changes not showing in browser
→ Hard refresh: Ctrl + Shift + R (or Cmd + Shift + R on Mac)
→ Or wait 5 seconds and refresh normally

❌ Vercel deployment fails
→ Check the deployment logs in Vercel dashboard
→ Make sure you have no syntax errors locally
→ Try pushing again: git push -u origin main
